# Online Exam - Google Apps Script

Source files prepared for upload to GitHub.

## Files
- `Index.html` — giao diện web app
- `Config.gs` — cấu hình
- `Database.gs` — truy xuất dữ liệu database / học phần / câu hỏi
- `ExamService.gs` — quản lý đề thi và câu hỏi trong đề
- `Repository.gs`
- `Auth.gs`
- `TeacherService.gs`
- `UploadService.gs`
- `SyncService.gs`
- `OverrideService.gs`
- `ReportService.gs`
- `TemplateService.gs`
- `PublicAPI.gs`
- `Utils.gs`

## Lưu ý
Các file `Index.html`, `Database.gs` và `ExamService.gs` được dựng lại từ các bản mã nguồn đã lưu trong cuộc trò chuyện/Library tại thời điểm đóng gói. Cần kiểm tra lại với Apps Script project hiện tại trước khi deploy.

Không đưa `DATABASE_ID`, mật khẩu, token hoặc thông tin bí mật vào GitHub công khai.
